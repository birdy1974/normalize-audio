# audio-normalizer

Self-hosted web app that checks audio files (MP3, FLAC, M4A, WAV, OGG, AVI/MKV/MP4 audio tracks, …)
in a chosen folder tree and brings their loudness to one common level, without changing the audio quality.
Designed for Docker on a Synology DS918+ NAS.

**Status: planning.** The brief is in [`requirements.md`](requirements.md).

- [`docs/ARCHITECTURE_PROPOSAL.md`](docs/ARCHITECTURE_PROPOSAL.md): proposed structure, technical findings and open questions.
- [`mockup/`](mockup/README.md): clickable UI prototype (no backend yet).

Implementation starts after the proposal and mock-up are approved.
